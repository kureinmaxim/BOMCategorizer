# 🎓 Лекция: Интеграция Шифрования в BOMCategorizer

## 1. Введение: Клиентская сторона безопасности

Мы уже реализовали серверную часть шифрования в `TelegramHelper`. Теперь наша задача — научить клиентское приложение (`BOMCategorizer`) "говорить" на этом защищенном языке.

**Задача:**
Обеспечить безопасную передачу промптов и получение ответов от AI-сервиса, чтобы ни один промежуточный узел (прокси, провайдер) не мог прочитать содержимое ваших запросов.

---

## 2. Реализация: Шаг за шагом

Мы внедрили поддержку шифрования **AES-256-GCM** прямо в ядро приложения.

### Шаг 1: Модуль шифрования (`bom_categorizer/encryption.py`)

Это "сердце" нашей безопасности. Мы создали зеркальную копию серверного класса `SecureMessenger`.

**Что он делает?**
1.  **Деривация ключа (HKDF):** Превращает ваш текстовый пароль в криптографически стойкий 256-битный ключ.
2.  **Шифрование (Encrypt):**
    *   Генерирует уникальный `Nonce` (случайное число) для каждого запроса.
    *   Шифрует JSON с данными.
    *   Формирует бинарный пакет: `[Версия][KeyID][Nonce][Шифротекст][Tag]`.
3.  **Расшифровка (Decrypt):**
    *   Разбирает ответ от сервера.
    *   Проверяет целостность данных (Tag).
    *   Возвращает чистый JSON.

### Шаг 2: Интеграция в AI Классификатор (`gui/ai_classifier.py`)

Мы модифицировали рабочий поток `AIClassifierWorker`, добавив нового провайдера — `telegram`.

**Ключевые изменения:**
*   **Новый метод `_classify_telegram`:**
    *   Использует `SecureMessenger` для шифрования промпта.
    *   Отправляет `POST` запрос на endpoint `/ai_query/encrypted`.
    *   Устанавливает заголовок `Content-Type: application/octet-stream`.
    *   Добавляет необходимые заголовки безопасности: `X-API-KEY`, `X-APP-ID`, `X-Timestamp`, `X-Nonce`.
*   **Настройки (`AIClassifierSettings`):**
    *   Добавлены поля `telegram_api_url` и `encryption_key`.
    *   Теперь пользователь может указать свой сервер и ключ шифрования.

### Шаг 3: Конфигурация (`config/config_qt.json.template`)

Мы обновили шаблон конфигурации, чтобы новые пользователи сразу получали правильную структуру настроек.

```json
"ai_classifier": {
    "enabled": false,
    "provider": "anthropic",
    ...
    "telegram_api_url": "http://localhost:8000",
    "encryption_key": "" 
}
```

## 3. Как это работает "под капотом"?

Представьте, что вы отправляете компонент "Resistor 10k" на классификацию.

1.  **BOMCategorizer**:
    *   Берет промпт: `{"prompt": "Классифицируй Resistor 10k..."}`.
    *   Шифрует его ключом `ENCRYPTION_KEY`.
    *   Получает бинарный "конверт".
    *   Отправляет конверт на сервер.

2.  **Сеть (Интернет)**:
    *   Хакер видит только бинарный мусор. Он не знает, что внутри.

3.  **TelegramHelper (Сервер)**:
    *   Получает конверт.
    *   Расшифровывает его тем же ключом.
    *   Видит промпт, отправляет его в Claude/GPT.
    *   Получает ответ: `{"category": "resistors"}`.
    *   Шифрует ответ и отправляет обратно.

4.  **BOMCategorizer**:
    *   Получает зашифрованный ответ.
    *   Расшифровывает и показывает вам результат: "Категория: Резисторы".
