# 📘 BOM Categorizer — GUIDE (руководство пользователя)

Этот документ описывает **как пользоваться Modern Edition (PySide6)** в разных режимах и какие файлы/результаты ожидать.

---

## ⚡ Быстрый старт (Windows)

- **Modern Edition (рекомендуется):** `scripts/run_modern_debug.bat`
- **Standard Edition:** `scripts/run_standard_debug.bat`

> Если запускаете из исходников: активируйте окружение и запустите `python app_qt.py`.

---

## 🧭 Режимы интерфейса (Modern Edition)

В меню **Вид → Режим работы**:

- **Простой режим**
  - Для ежедневной работы.
  - Скрывает «опасные» и редкие функции.
- **Расширенный режим**
  - Все основные функции доступны (обработка, объединение BOM+ТРУ, экспорт PDF и т.д.).
- **Экспертный режим**
  - Дополнительные настройки и сервисные функции.
  - Обычно защищён PIN‑кодом (если включено).

---

## ✅ Основные сценарии

## 1) Обработка BOM (классификация)

1. Добавьте входные файлы BOM (Excel/Word/TXT).
2. Нажмите **Запуск обработки**.
3. На выходе получится Excel с категориями (листы по категориям) + `SUMMARY`.
4. Если остались элементы в листе **«Не распределено»**:
   - запустите интерактивную разметку (если используете),
   - либо разнесите вручную и пересохраните.

---

## 2) Обработка ТРУ/РКМ (получить *_tpy.xlsx)

1. Добавьте ТРУ/РКМ файлы в список ТРУ/РКМ.
2. Запустите обработку ТРУ/РКМ.
3. Итог для ТРУ: файл **`*_tpy.xlsx`** (например `ТРУ.953033.7412_tpy.xlsx`).

---

## 3) Совместная обработка BOM + ТРУ (merge)

### Какие ТРУ файлы использовать

Для merge режима используйте **только уже обработанные ТРУ файлы**:

- ✅ `ТРУ.953033.7412_tpy.xlsx`
- ❌ исходные `ТРУ.953033.7412.xls` (их сначала нужно обработать в режиме ТРУ/РКМ)

Приложение теперь подсказывает это при добавлении файлов и блокирует merge, если в списке есть не `*_tpy.xlsx`.

### Что получается на выходе

После merge создаются:

- **`*_тру.xlsx`** — основной результат объединения (плюс лист «Несопоставленные ТРУ», если есть).
- **`*_ostatki.xlsx`** + **`*_ostatki.pdf`**
  - позиции из BOM, которых нет в ТРУ
  - позиции, где в ТРУ количество меньше, чем в BOM (в файл пишется разница)
- **`*_zapas.xlsx`** + **`*_zapas.pdf`**
  - несопоставленные ТРУ
  - позиции, где в ТРУ количество больше, чем в BOM (в файл пишется разница)

### Прогресс

В merge режиме показывается **всплывающее окно прогресса** (чтение ТРУ → чтение BOM → merge → сохранение → PDF).

---

## 🖨 PDF экспорт

- Для `_ostatki` и `_zapas` PDF создаётся автоматически.
- Для основного результата можно экспортировать в PDF через функцию экспорта в GUI.

---

## 🧩 Советы

- Если в merge у «наших» позиций внезапно появляется `№ ТРУ/Стоимость`, проверьте что:
  - вы используете **`*_tpy.xlsx`**, а не исходный `.xls`,
  - в «Название/ТУ» корректно выделяются коды (ГВАТ/АМФИ/ИГНД/де…).
