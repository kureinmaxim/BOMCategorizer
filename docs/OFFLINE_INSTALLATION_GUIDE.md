## 💿 Способ 1: Установка через Инсталлятор (Рекомендуется)

Самый простой способ. Инсталлятор уже содержит все необходимые библиотеки.

### Шаг 1: Подготовка (на ПК с интернетом)

Получите файл инсталлятора:
- `BOMCategorizerSetup.exe` (Standard Edition)
- `BOMCategorizerModernSetup.exe` (Modern Edition)

> 💡 Если вы разработчик и собираете инсталлятор сами, убедитесь, что папка `offline_packages` заполнена (см. [BUILD.md](../BUILD.md)).

### Шаг 2: Перенос

Скопируйте `.exe` файл на флешку.

### Шаг 3: Установка (на ПК без интернета)

1. Вставьте флешку в целевой компьютер
2. Запустите `.exe` файл
3. Следуйте инструкциям мастера установки

> ✅ Инсталлятор автоматически распакует встроенный Python и все библиотеки. Интернет не потребуется.

## 🎒 Способ 2: Перенос Portable версии

Если инсталлятор использовать нельзя, можно перенести настроенную версию вручную.

### Шаг 1: Подготовка (на ПК с интернетом)

1. Скачайте исходный код проекта
2. Подготовьте папку `offline_packages` (см. раздел ниже)
3. Скачайте установщик Python 3.13 с [python.org](https://www.python.org/downloads/)

### Шаг 2: Перенос

Скопируйте на флешку:
- Папку с исходным кодом проекта
- Папку `offline_packages`
- Установщик Python (если на целевом ПК его нет)

### Шаг 3: Настройка (на ПК без интернета)

```powershell
# 1. Скопируйте файлы с флешки (например, в C:\Apps\BOMCategorizer)

# 2. Установите Python (если нужно)

# 3. Откройте PowerShell в папке проекта

# 4. Создайте виртуальное окружение
python -m venv .venv

# 5. Активируйте его
.\.venv\Scripts\Activate

# 6. Установите зависимости из локальной папки
pip install --no-index --find-links=offline_packages -r requirements.txt
```

> 💡 Флаг `--no-index` запрещает обращаться к PyPI, а `--find-links` указывает брать пакеты из папки.

## 📥 Подготовка offline_packages

### Содержимое папки

Для работы приложения нужны `.whl` файлы для **Python 3.13 (Windows x64)**.

| Библиотека | Файл (пример) | Назначение |
|------------|---------------|------------|
| **Pandas** | `pandas-2.2.3-cp313-cp313-win_amd64.whl` | Обработка таблиц |
| **NumPy** | `numpy-2.1.3-cp313-cp313-win_amd64.whl` | Математика (для Pandas) |
| **OpenPyXL** | `openpyxl-3.1.5-py2.py3-none-any.whl` | Чтение/запись Excel |
| **Python-Docx** | `python_docx-1.1.2-py3-none-any.whl` | Чтение Word файлов |
| **PySide6** | `PySide6-6.8.0-cp37-abi3-win_amd64.whl` | GUI (Modern Edition) |
| **Shiboken6** | `shiboken6-6.8.0-cp37-abi3-win_amd64.whl` | Зависимость PySide6 |
| **LXML** | `lxml-5.3.0-cp313-cp313-win_amd64.whl` | Обработка XML |
| **Tqdm** | `tqdm-4.67.0-py3-none-any.whl` | Прогресс-бары |
| **Colorama** | `colorama-0.4.6-py2.py3-none-any.whl` | Цвета в консоли |
| И другие... | `six`, `python-dateutil`, `tzdata` | Мелкие зависимости |

> 📊 **Всего:** ~15-20 файлов, ~100-150 МБ (основной вес — PySide6)

### Как скачать пакеты

Выполните на компьютере **с интернетом**:

```powershell
# 1. Создайте папку
mkdir offline_packages

# 2. Скачайте ВСЕ пакеты одной командой
pip download -r requirements_install.txt `
    -d offline_packages `
    --platform win_amd64 `
    --python-version 313 `
    --only-binary=:all: `
    --prefer-binary
```

> 💡 Используем `requirements_install.txt`, чтобы не качать лишние библиотеки для тестирования. Если файла нет — используйте `requirements.txt`.

✅ Готово! Скопируйте папку `offline_packages` на флешку.

## 🐛 Решение проблем

### Ошибка "Missing dependencies"

Приложение жалуется на отсутствие модулей (`pandas`, `PySide6` и т.д.):

1. Убедитесь, что активировали виртуальное окружение:
   ```powershell
   .\.venv\Scripts\Activate
   ```
2. Переустановите зависимости:
   ```powershell
   pip install --no-index --find-links=offline_packages -r requirements.txt
   ```

### Ошибка "Python не найден"

- Убедитесь, что Python добавлен в PATH при установке
- Или используйте полный путь: `C:\Python313\python.exe`

### Ошибка "No matching distribution found"

Пакет в `offline_packages` не подходит для вашей версии Python или платформы:

1. Проверьте версию Python: `python --version`
2. Перескачайте пакеты с правильными параметрами `--python-version` и `--platform`
