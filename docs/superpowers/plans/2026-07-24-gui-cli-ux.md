# GUI CLI UX Implementation Plan

> **For agentic workers:** Implement task-by-task. Steps use checkbox syntax.

**Goal:** Improve in-app Interactive CLI UX (hints, quoting, theme-aware colors) per spec `docs/superpowers/specs/2026-07-24-gui-cli-ux-design.md`.

**Architecture:** Pure helpers in `bom_categorizer/cli_ux.py`; `cli_interactive.py` uses them for parse/fuzzy/palette/usage. No new business commands.

**Tech Stack:** Python 3.13, PySide6, pytest, shlex

## Global Constraints

- No new BOM/AI/version commands
- Windows paths with spaces must work (`shlex`, `posix=False`)
- Theme from `main_window.current_theme`
- Keep handlers in `cli_interactive.py`
