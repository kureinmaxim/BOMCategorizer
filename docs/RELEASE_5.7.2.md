# Modern Edition 5.7.2

Версия 5.7.2 содержит исправление классификации собственных разработок.

Коды `ДЕ1`, `ДЕ-1`, `ДЕ 1.234`, `DE1`, `Е1`, а также символы шрифта Word/Symbol
(`¶e`, математический курсив `𝑑e`) и записи номера словами относятся к
категории «Наши разработки». Это правило имеет приоритет над устаревшей категорией,
сохранённой во входном XLSX. Код сохраняется в колонке «ТУ/Производитель».

Проверка добавлена в регрессионные тесты. После сборки инсталлятора проверьте старый
выходной файл повторной обработкой исходного документа: уже созданный XLSX сам по
себе не переклассифицируется, если его открыть как готовый результат.

Сборка:

```powershell
python deployment/build_installer.py
```

Выберите `2 — Modern Edition`; ожидаемый номер версии — `5.7.2`.

### Исправление DOC→DOCX
Если Word удаляет первый символ в коде вида 5.067.066-03, версия 5.7.2 восстанавливает его как ДЕ5.067.066-03 и относит строку в «Наши разработки».
