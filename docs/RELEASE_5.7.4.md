# Modern Edition 5.7.4

Дата: 07.10.2026.

После записи результата приложение закрывает все объекты `pandas.ExcelFile`, поэтому созданный XLSX можно удалить или переместить, пока программа остаётся открытой.

Также сохранено исправление классификации EVAL-плат: `EVAL-ADF4351EB1Z` относится к отладочным платам даже при обозначении `W3`.

Для сборки выполните `python deployment/build_installer.py` и выберите Modern Edition 5.7.4.
