# Руководство пользователя BOM Categorizer

BOM Categorizer — это инструмент для автоматической классификации компонентов из спецификаций (BOM) в формате DOCX, XLSX и TXT. Программа распределяет компоненты по категориям (Резисторы, Микросхемы, СВЧ модули и т.д.) и формирует итоговый отчет.

## 1. Быстрый старт

1.  **Запуск**: Откройте приложение `BOMCategorizer`.
2.  **Выбор файла**: Нажмите кнопку **"Выбрать..."** напротив поля "Входные файлы" и выберите ваш BOM-файл (поддерживаются `.docx`, `.xlsx`, `.txt`).
3.  **Настройка**:
    *   Укажите количество экземпляров (по умолчанию 1).
    *   Галочка **"Исключить подборы"** уберет из отчета альтернативные компоненты.
4.  **Запуск**: Нажмите **"Запустить обработку"**.
5.  **Результат**: После завершения откроется папка с результатом. Файл будет называться `..._categorized.xlsx`.

---

## 2. Как работает классификация

Программа определяет категорию компонента в следующем порядке приоритетов:

1.  **База знаний (Database)** 🥇
    *   Самый высокий приоритет.
    *   Если компонент (например, `MTS-18XL-B`) есть в базе, он *всегда* попадет в указанную там категорию, игнорируя любые другие правила.
    
2.  **Автоматические правила (Rules)** 🥈
    *   Если компонента нет в базе, программа анализирует его название.
    *   Используются ключевые слова (например, "Resistor", "мкФ", "SOT-23") и префиксы.

3.  **Не распределено (Unclassified)** ❓
    *   Если программа не смогла определить категорию, компонент попадает в категорию "Не распределено".

## 3. Интерактивный режим

Если после обработки остались нераспределенные компоненты, используйте интерактивный режим для обучения программы.

1.  Нажмите кнопку **"Интерактивная классификация"** (она станет активной, если есть нераспределенные элементы).
2.  Откроется окно со списком неизвестных компонентов.
3.  Для каждого компонента выберите категорию нажатием кнопки.
4.  ✅ **Важно**: Ваш выбор **автоматически сохраняется** в базу знаний. В следующий раз этот компонент (и похожие) будут распознаны автоматически!

## 4. Настройка правил (База знаний)

Вы можете вручную корректировать классификацию, если программа ошибается (например, относит СВЧ-переключатель к "Микросхемам" вместо "СВЧ модулей").

### Способ А: Через Excel (Рекомендуемый)

Самый простой способ массового редактирования правил.

1.  В меню выберите **База данных -> Экспорт в Excel**.
2.  Сохраните файл `component_database_export.xlsx`.
3.  Откройте файл в Excel. Вы увидите две колонки:
    *   `Component Name` (Название компонента)
    *   `Category` (Код категории)
4.  **Для исправления ошибки**:
    *   Найдите компонент (Ctrl+F).
    *   Измените код категории на правильный (см. [Справочник категорий](#6-справочник-категорий)).
5.  **Для добавления нового правила**:
    *   Добавьте новую строку в конец таблицы.
    *   Впишите точное название компонента и код категории.
6.  Сохраните файл Excel.
7.  В программе выберите **База данных -> Импорт из Excel** и загрузите измененный файл.

### Способ Б: Редактирование JSON (Для опытных)

Прямое редактирование файла базы данных.

1.  В меню выберите **База данных -> Открыть папку БД**.
2.  Найдите файл `component_database.json`.
3.  Сделайте резервную копию файла!
4.  Откройте его в текстовом редакторе (Notepad++, VS Code).
5.  Добавьте или измените запись в формате:
    ```json
    "Название компонента": "код_категории"
    ```
6.  Сохраните файл и перезапустите программу.

## 5. Устранение неполадок

### Проблема: В названии компонента остался текст "с подбором"
**Решение**: Программа автоматически очищает текст "с подбором" и "с подбором..." из названий. Если вы видите этот текст:
1.  Убедитесь, что у вас последняя версия программы.
2.  Попробуйте запустить обработку файла заново (очистка происходит при чтении файла).

### Проблема: Компонент попадает не в ту категорию
**Решение**: 
1.  Используйте **Интерактивную классификацию** для быстрого исправления.
2.  Или добавьте компонент в базу знаний через Excel (см. раздел 4).

### Проблема: Ошибка при запуске обработки
**Решение**: Убедитесь, что исходный файл не открыт в Word или Excel. Закройте файл и попробуйте снова.

## 6. Справочник категорий

Используйте эти коды (на английском) при редактировании базы данных в Excel или JSON.

| Код (Category) | Русское название | Описание |
| :--- | :--- | :--- |
| `resistors` | **Резисторы** | Все виды резисторов |
| `capacitors` | **Конденсаторы** | Все виды конденсаторов |
| `inductors` | **Индуктивности** | Дроссели, катушки |
| `ics` | **Микросхемы** | Микросхемы, чипы, логика |
| `semiconductors` | **Полупроводники** | Диоды, транзисторы, тиристоры |
| `connectors` | **Разъемы** | Соединители, клеммы, переходы |
| `rf_modules` | **СВЧ модули** | Аттенюаторы, делители, СВЧ-переключатели |
| `cables` | **Кабели** | Провода, кабельные сборки |
| `dev_boards` | **Отладочные платы** | Платы Arduino, Nucleo, Discovery и др. |
| `power_modules` | **Модули питания** | DC-DC, AC-DC преобразователи |
| `optics` | **Оптика** | Оптические кабели, трансиверы |
| `our_developments`| **Наши разработки** | Платы собственного производства, ОСТ |
| `others` | **Другие** | Крепеж, материалы, неопознанное |
| `non_bom` | **Не входит в BOM** | Служебные строки, заголовки |
